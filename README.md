# Practical Item Filter – Polish Edition

This mod is a **Polish localized and enhanced version** of:

**Practical Item Filter for D2RMM**  
by **NDState**  
https://www.nexusmods.com/diablo2resurrected/mods/317

---

## Credits

All credit for the original concept, base structure and initial implementation
goes to the original author of **Practical Item Filter for D2RMM**.

This modified version adds:
- Full Polish localization
- ASCII-only symbols (Diablo 2 font safe)
- Improved visibility of runes (Pul+)
- Added support for keys, essences and organs
- Improved gem tier highlighting
- Font consistency fixes

This project is **non-commercial** and shared for the community.
